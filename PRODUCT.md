# Melly

## Register

product

## Users

Mac users who want fast, quiet cloud conversations with their chosen providers, often moving between a bright workspace and a dim evening room. Both light and dark appearance are first-class.

## Product Purpose

An instant-feeling native chat app with persistent conversations, intentional organization and explicit reference access. Rust owns persistence, streaming, cancellation and trust boundaries. The frontend stays thin.

## Brand Personality

Quiet, precise, confident. Follow the approved Ollama-inspired restraint: system typography, ordinary weights, a narrow sidebar and one composer. Melly has its own black-and-white conversation mark.

## Anti-references

Dashboards, heavy cards, decorative gradients, oversized headings, noisy status badges, silver icon frames and coding tools inside ordinary chat. Files, coding and a knowledge graph are brainstorming only until separately authorized.

## Design Principles

- Make common actions immediate and easy to discover.
- Reveal secondary controls on hover, focus or an intentional menu.
- Preserve the conversation and scroll position during organization.
- Make billing, source scope and actual connection state truthful.
- Spend work only when needed; no startup network or idle animation loops.

## Accessibility & Inclusion

Use semantic controls, visible keyboard focus, a non-drag alternative for every move, readable code colors in both themes and reduced-motion support. Never make color the only indication of a drop target.
