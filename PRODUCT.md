# Product

## Register

product

## Users

Developers coding in a terminal for extended sessions, switching between models and watching delegated work. The user wants to get the most useful coding work from a Codex subscription with little friction or overhead.

## Product Purpose

A fast Rust workspace around real Codex sessions. Make model selection, reasoning effort, live activity, context and usage understandable without extra conversations with the model.

## Brand Personality

Quiet, precise, distinctive. Use OpenCode's restrained chat structure as the baseline, with Melly's own pixel lettering and activity rhythm. Near-black tinted graphite, warm text, the user's selected accent, and mint for positive status. The interface should feel crafted without competing with the work.

## Anti-references

The user dislikes the sparse, visually monotonous stock terminal and the first Melly milestone's empty panes. Avoid decorative dashboards, fake metrics, hidden busy states and controls that require memorizing commands.

## Design Principles

- Show what the session is doing immediately.
- Keep frequent actions one or two keystrokes away.
- Preserve the conversation while changing settings.
- Separate measured tokens, context estimates and account quota.
- Keep model work and local interface work distinct.

## Accessibility & Inclusion

Every action works from the keyboard. Text labels accompany color. Adapt to small terminal sizes. Respect the terminal's chosen monospace font. A brief logo reveal is allowed; ongoing motion conveys live work. Animation never delays input, respects the motion setting, and stops when idle.
