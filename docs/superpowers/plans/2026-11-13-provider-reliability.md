# Provider reliability

User goal: improve all supported chat providers, including Claude where possible, without treating an untested account or a subscription as a verified API connection. These are incremental changes to the existing chat product, not a coding host, subscription workaround, voice feature, or new billing route.

1. **Discovery:** Request up to the existing 1,000-model bound in one documented page for Claude and Gemini. Hide Gemini entries explicitly reporting no content-generation method, retaining entries whose capability is unknown and the manual model-ID path. Preserve other endpoints, request-scoped credentials, cancellation, error handling, and no startup network. Tests use synthetic provider responses and do not claim live access.
2. **Claude mixed search:** Reassemble streamed `server_tool_use` arguments independently of client tool calls, and replay validated original blocks when continuing a mixed server/client turn. Invalid fragments fail closed before dispatch. Test byte-fragmented frames, both tool orders, and the generated continuation request.
3. **Actionable provider errors:** Map HTTP status codes to concise, non-secret guidance while retaining the status and provider. Do not parse error bodies, trigger retries, change endpoints, or infer a billing/entitlement cause. Tests cover common statuses, cancellation and reflected secrets.
4. **Verification:** Run focused red/green checks, complete Rust and UI suites, TypeScript/format/Clippy checks, release build and strict signature check. Use local fixture servers only; no real keys, network inference, or production account changes. Verify the native build if its signing/permission state permits without disturbing the user's account. Record limits and push feature-sized checkpoints on `main` as authorized.

References: [Claude model list](https://platform.claude.com/docs/en/api/models/list), [Gemini model list](https://ai.google.dev/api/models), [Claude server tools](https://platform.claude.com/docs/en/agents-and-tools/tool-use/server-tools), [Claude streamed search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool), and [Claude HTTP errors](https://platform.claude.com/docs/en/api/errors).
